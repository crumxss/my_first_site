О проекте

Это мой учебный первый проект. Здесь я учусь делать сайты на html, css и javascript.

Теперь на сайте работает JavaScript: меняются классы, проверяется форма и подгружаются данные из JSON.

Что я использовала

  • HTML - для структуры страниц
  • CSS и Bootstrap - для цветов, шрифтов, сетки и компонентов
  • JavaScript - для событий, проверки формы и загрузки данных
  • GitHub Pages - чтобы опубликовать сайт

Что я узнала

  1. Как устроена HTML страница (head и body)
  2. Что такое теги и атрибуты
  3. Семантические теги: header, nav, main, section, footer
  4. Как подключить style.css и script.js
  5. Как сделать так чтобы сайт нормально выглядел на телефоне
